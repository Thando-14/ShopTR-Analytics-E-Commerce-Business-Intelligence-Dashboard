# ShopTR-Analytics-E-Commerce-Business-Intelligence-Dashboard
This project was developed as part of the Business Intelligence module for the Advanced Diploma in Information and Communication Technology programme. The goal of the project was to transform raw e-commerce transaction data into a professional and interactive Business Intelligence dashboard for executive decision-making.

# The dashboard provides insights into:

Sales performance
Customer behaviour
Product trends
Device usage
Delivery performance
Customer satisfaction
RFM customer segmentation
Digital engagement analytics

The project simulates a real-world client engagement for a Turkish online retail platform using descriptive analytics techniques.

# Dataset used:

E-Commerce Customer Behaviour and Sales Analysis – TR

Source: Kaggle
Kaggle Dataset

# Data Preparation

The dataset was cleaned and transformed using Power Query.

Data preparation included:
Correcting data types
Removing duplicates
Handling missing values
Detecting outliers using the IQR method
Validating calculated totals
Creating derived analytical features
Engineered Features

# The following calculated fields were created:

Order_Year
Order_Quarter
Order_MonthName
Day_of_Week
Age_Group
Discount_Flag
Discount_Rate_%
Engagement_Tier
RFM_Segment

# Dashboard Features
The dashboard contains:

KPI Cards
Monthly Revenue Trend Analysis
Revenue by Product Category
Geographic Revenue Analysis
Device Type Analysis
Payment Method Distribution
Customer Satisfaction Metrics
RFM Segment Treemap
Delivery Time vs Customer Rating
Returning vs New Customer Comparison
Interactive Slicers & Filters

# Key Business Insights
The analysis helped identify:

High-performing product categories
Customer purchasing behaviour
Revenue-driving cities

Relationships between engagement and spending
